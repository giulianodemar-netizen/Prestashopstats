# Quick Start Guide

Get started with PrestaShop Statistics Module in minutes!

## Installation (1 minute)

1. Upload module folder to `/modules/prestashopstats/`
2. Go to **Modules** > **Module Manager**
3. Search for "PrestaShop Statistics"
4. Click **Install**

✅ Done!

## First Look (30 seconds)

1. Go to **Stats** menu in admin
2. Click **Statistics Dashboard**
3. You'll see:
   - 📊 Sales statistics
   - 👥 Customer insights
   - 📦 Product metrics
   - 🌍 Geolocation data
   - 📈 Traffic analytics

## Filter by Date Range (15 seconds)

At the top of dashboard:
1. Select **From** date
2. Select **To** date
3. Click **Filter**

View statistics for any time period!

## What You'll See

### Sales Section
- **Total Orders** - Number of completed orders
- **Total Revenue** - Total money earned
- **Top Products** - Best sellers by revenue
- **Top Customers** - Biggest spenders

### Customer Section
- **Total Customers** - All active customers
- **New Customers** - Recently registered
- **By Country** - Where customers are from
- **Purchase Frequency** - Customer loyalty levels

### Product Section
- **Most Purchased** - Products with most sales
- **Most Viewed** - Popular product pages
- **By Category** - Which categories sell best

### Geolocation Section
- **Orders by Country** - Where orders come from
- **Traffic by Country** - Visitor locations

### Traffic Section
- **Total Visits** - Number of visitors
- **Page Views** - Pages browsed
- **Conversions** - Completed purchases
- **Conversion Rate** - Success percentage
- **Traffic Sources** - Where visitors come from

## Common Tasks

### View Last 30 Days
Default view shows last 30 days automatically

### View Last Week
Set date range from 7 days ago to today

### View This Month
Set date range from 1st of current month to today

### Compare Periods
1. Note statistics for Period A
2. Change date range to Period B
3. Compare the numbers

## Tips

💡 **Best Practices:**
- Check daily to monitor trends
- Compare week-over-week performance
- Identify top products to stock more
- Target top customer countries
- Optimize based on traffic sources

🎯 **Key Metrics to Watch:**
- Conversion rate (higher is better)
- Average order value (revenue ÷ orders)
- Customer retention (repeat orders)
- Traffic growth (visits over time)
